# Drzewko pracy w Git

W projekcie przygotowano podstawowe branche:

- `main` - wersja koncowa,
- `env-qa` - wersja do sprawdzenia jakosci,
- `env-test` - wersja testowa.

Branche zadaniowe:

- `feat/stworzenie-aplikacji-gui` - utworzenie okien tkinter i logowania,
- `feat/dodanie-modelu-danych` - utworzenie danych firm, magazynow i pracownikow,
- `feat/dodanie-crud` - dodawanie, edycja i usuwanie danych,
- `feat/dodanie-mapy` - dodanie mapy i znacznikow,
- `feat/dodanie-filtrowania` - filtrowanie danych w tabelach i na mapie,
- `feat/dokumentacja-projektu` - README, wymagania i opis branchy.

Kierunek pull requestow:

1. Branch zadaniowy -> `env-test`
2. `env-test` -> `env-qa`
3. `env-qa` -> `main`

Przykladowe commity:

- `feat: dodanie modelu danych`
- `feat: stworzenie aplikacji gui`
- `feat: dodanie operacji crud`
- `feat: dodanie mapy z obiektami`
- `feat: dodanie filtrowania list i mapy`
- `feat: dodanie dokumentacji projektu`
